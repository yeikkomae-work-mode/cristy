# Cristy Jane Muñosco, portfolio website

Static site, no build step. Open `index.html`, or enable GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).

- `index.html` portfolio (desktop and mobile layouts switch at 760px)
- `resume.html` resume page; the nav Resume link opens the Google Drive PDF
- `certificates.html` certificates page; the nav Certificates link opens the Google Drive folder
- `assets/` project images and tool graphics
- `design/` source boards from the Claude Design canvas (`.dc.html`, `canvas.json`)

Palette: brown #ad8e70, yellow #ffebb7, orange #ff6e31, navy #243763. Fonts: Cormorant Garamond, Inter, Anton.
